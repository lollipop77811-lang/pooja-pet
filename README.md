# Restaurant SaaS

A multi-tenant SaaS platform designed for restaurant operations, online ordering, and management.
Built as a modern TypeScript monorepo using pnpm workspaces.

## Getting Started

### Installation

```bash
pnpm install
```

### Development & Build

```bash
# Start development server (once apps are configured)
pnpm dev

# Build all packages and applications
pnpm build

# Run linting
pnpm lint

# Run tests
pnpm test
```
